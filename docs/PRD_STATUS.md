## Measurement and accessibility

- **Schema target:** 30/30 local Gemma outputs were schema-valid. Exact raw planner intent matches were 19/30 after sharing the bounded prompt, compared with 11/30 under the old example prompt. This is an authored regression set inspected during prompt correction, not unseen test data. Hosted Tinker normalization is evaluated separately.
- **Ten workflows:** all completed with 24 triages, two actual model drafts, two explicit scripted reply decisions, Mastra success and Temporal completion. Local text-to-plan p50/p95: **9.44/23.42 s**. Preparation to two decisions p50/p95: **17.19/31.97 s**. Startup p50/p95: **1.60/4.29 s**, separately. Models were resident in all ten runs. Nearest-rank p95 at n=10 is the slowest sample. [Full receipts](evidence/local-performance.json).
- **Cloud voice performance:** not measured across ten runs. The fresh hosted run is a functional check, not a ten-run voice performance benchmark; local text measurements cannot substitute for that PRD target.
- **Manual benefit:** [timing sheet](LAZY_PAYOFF.md) remains empty. No manual time, correction time or minutes saved has been invented.
- **Accessibility:** axe-core checks, mobile widths and actual OS reduced-motion toggling are recorded under [accessibility evidence](evidence/accessibility/). Normal OS motion and the original browser viewport were restored afterward. Keyboard focus wraps within approvals, Escape dismisses dialogs and restores mobile navigation focus. Zero automated violations in the checked views does not establish full WCAG conformance; axe's incomplete checks remain in the raw reports.
- **Quality:** a correct JSON schema does not guarantee useful replies. The saved drafts remain available for review, and the sample set is fictional.
